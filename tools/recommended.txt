
This is an incomplete list of tools we use when developing the practice hack.


P.JBoy's bank logs - https://patrickjohnston.org/bank/index.html
Complete documentation of the Super Metroid ROM, easily viewable in your browser or downloaded as text. The RAM map linked within is essential.

Mesen - https://mesen.ca
Mesen is currently the most accurate SNES emulator. It includes a very powerful suite of debugging tools. Drag and drop our symbols file (generated by build_dev.bat) to get our source code labels in the debugger. Highly recommended for hacking and casual exploration!

Notepad++ - https://notepad-plus-plus.org/
Any text editor will do, but we like Notepad++.

YY-CHR - https://w.atwiki.jp/yychr
A pixel editor that supports retro console graphics in their native formats. We use it to edit our HUD and menu graphics with the 2BPP GB format option, and 4BPP SNES for sprites. While the website is in Japanese, the application is localized to English based on your PC settings.

Lunar IPS - https://fusoya.eludevisibility.org/lips/
A simple patching tool for creating and applying IPS files. build_dev.bat will try to patch the ROM with Lunar IPS if included.

Lunar Address - https://fusoya.eludevisibility.org/la/
Translates SNES address space to PC (ROM file) format. Super Metroid uses LoROM 80:8000 - FF:FFFF ROM type. We always work with headerless ROMs.

HxD - https://mh-nexus.de/en/hxd/
A popular hex editor. We don't do much hex editing these days (that's what ASM is for!) but the file compare feature can be useful at times.

SMILE RF - https://metroidconstruction.com/SMMM/SMILE_RF_3.0.80_offline.zip
Super Metroid Integrated Level Editor. We don't use it to edit anything, but it can still be useful for research. The tooltip that appears when you select a tile and press tilda (`) is particularly handy. SMART is a newer editor with most of the same tools and more, but one of its main goals is to repoint things in the ROM and manage a hack project. We don't need any of that.

Snes9x-rr v1.51 - https://github.com/TASEmulators/snes9x-rr/releases/tag/snes9x-151-v7.1
The teledump lua script was written for this particular version of Snes9x. It is needed to create new category presets.
